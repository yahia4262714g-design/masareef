# مصاريف

**تطبيق شخصي لإدارة المصاريف — عربي بالكامل، يعمل بدون إنترنت، وبياناتك تبقى على جهازك.**

## شو هذا التطبيق؟

تطبيق ويب (PWA) تثبّته على شاشة الآيفون الرئيسية فيشتغل مثل أي تطبيق عادي.
فكرته الأساسية إنك تكتب جملة عربية عادية:

> صرفت 5 شيكل قهوة

والتطبيق يفهم لحاله: **المبلغ** ٥ · **العملة** شيكل · **النوع** مصروف · **الفئة** قهوة ومشروبات · **التاريخ** اليوم.

بعد شهر أو شهرين من الاستخدام يصير يقدر يجاوبك: وين بتصرف أكثر؟ هل مصروفك ارتفع؟ قدّيش ممكن توفّر؟

---

## أهم شي لازم تعرفه ⚠️

**بياناتك محفوظة على جهازك فقط.** ما في سيرفر ولا حساب ولا تسجيل دخول. هذا ممتاز للخصوصية، بس معناه:

- إذا مسحت بيانات المواقع من إعدادات Safari → بياناتك تروح.
- إذا حذفت التطبيق من الشاشة الرئيسية → بياناتك تروح.
- إذا غيّرت الجهاز → بياناتك ما بتنتقل لحالها.

👈 **خُذ نسخة احتياطية كل فترة** من: المزيد ← النسخ الاحتياطي ← تصدير نسخة احتياطية، واحفظ الملف في تطبيق «الملفات» أو أرسله لنفسك على الإيميل.

## التثبيت على الآيفون 📱

1. افتح رابط التطبيق في **Safari** (لازم Safari، مش Chrome).
2. اضغط زر **المشاركة** ⬆️ في شريط الأدوات السفلي.
3. مرّر لتحت واختر **«إضافة إلى الشاشة الرئيسية»**.
4. اضغط **«إضافة»**.

بعدها تلاقي أيقونة «مصاريف» على شاشتك، وتفتح بدون شريط عناوين Safari — مثل أي تطبيق.

> **ملاحظة:** أول مرة تفتحه لازم يكون عندك إنترنت حتى يحمّل الملفات ويخزّنها. بعدها يشتغل أوفلاين.

## التشغيل على الكمبيوتر (Windows)

تحتاج **Node.js** نسخة 20 أو أحدث. حمّله من [nodejs.org](https://nodejs.org) واختر نسخة LTS.

افتح موجّه الأوامر (Command Prompt) داخل مجلد المشروع ونفّذ:

```bash
# ١) تنصيب المكتبات — مرة واحدة فقط
npm install

# ٢) تشغيل التطبيق للتطوير
npm run dev
```

بعدها افتح المتصفح على العنوان اللي بيظهر لك (عادة `http://localhost:5173`).

### أوامر ثانية

```bash
npm run build     # بناء النسخة النهائية داخل مجلد dist
npm run preview   # تجربة النسخة النهائية محليًا قبل النشر
npm test          # تشغيل الاختبارات
npm run icons     # إعادة توليد أيقونات التطبيق
```

## النشر مجانًا 🚀

المشروع مُعدّ للنشر التلقائي على **GitHub Pages** — ما بتحتاج أي حساب أو خدمة خارجية.

### كيف يشتغل

في ملف `.github/workflows/deploy.yml`. كل ما ترفع تعديل على فرع `main`:

1. GitHub يشغّل الاختبارات ويفحص الأنواع.
2. لو نجح كل شي، يبني المشروع.
3. ينشره تلقائيًا على الرابط.

**لو فشلت الاختبارات ما ينشر** — حماية من نشر نسخة مكسورة.

### أول مرة فقط

الغالب إنه يفعّل نفسه تلقائيًا. لو ما اشتغل:

**Settings** ← **Pages** ← تحت **Source** اختر **GitHub Actions** ← احفظ.

بعدها من تبويب **Actions** شغّل **«نشر التطبيق»** يدويًا مرة واحدة.

### الرابط

```
https://<اسم-حسابك>.github.io/masareef/
```

تلاقيه كمان في: **Settings** ← **Pages**.

> **ملاحظة:** GitHub Pages المجاني يحتاج المستودع يكون **عامًا (public)**. هذا يكشف الكود فقط — مصاريفك ما بتطلع من جهازك إطلاقًا، ما في سيرفر يستقبلها أصلًا.

<details>
<summary>بدائل أخرى</summary>

**Cloudflare Pages** — يشتغل مع المستودعات الخاصة كمان، ويعطي رابطًا أحلى:

1. [dash.cloudflare.com](https://dash.cloudflare.com) ← **Workers & Pages** ← **Create** ← **Pages** ← **Connect to Git**
2. اختر المستودع، وعبّي: `Vite` / `npm run build` / `dist`
3. **Save and Deploy**

**Vercel** — نفس السهولة، اربط المستودع واترك إعدادات Vite الافتراضية.

**البناء اليدوي لأي مسار فرعي:**

```bash
# على Windows
set VITE_BASE=/اسم-المجلد/ && npm run build

# على Mac/Linux
VITE_BASE=/اسم-المجلد/ npm run build
```

التطبيق يستخدم `HashRouter` ومسارات نسبية، فيشتغل صح من أي مجلد.

## كيف أحدّث التطبيق؟

لما تنشر نسخة جديدة، التطبيق **ما يحدّث نفسه تلقائيًا** — هذا مقصود حتى لا ينقطع شغلك فجأة.

بدل هيك، يظهر لك شريط صغير أسفل الشاشة مكتوب فيه «في نسخة جديدة من التطبيق» مع زر **تحديث**. اضغطه لما تكون جاهز. بياناتك ما تتأثر إطلاقًا.

## النسخ الاحتياطي والاستعادة 💾

### أخذ نسخة

المزيد ← **النسخ الاحتياطي** ← **تصدير نسخة احتياطية**

بينزل ملف اسمه مثل `masareef-2026-09-12.json` فيه كل شي: العمليات، الفئات، الميزانيات، الأهداف، والإعدادات.

على الآيفون، بعد التنزيل اختر **حفظ في الملفات** واحفظه في iCloud Drive حتى يكون بأمان.

فيه كمان **تصدير جدول العمليات (CSV)** إذا بدك تفتح مصاريفك في Excel أو Numbers — بس انتبه: ملف CSV **ما ينفع للاستعادة**، هو للعرض والتحليل فقط.

### الاستعادة

المزيد ← **النسخ الاحتياطي** ← **اختر ملف النسخة**

قبل ما يتغيّر أي شي، التطبيق:

1. يفحص الملف ويتأكد إنه نسخة صالحة من مصاريف.
2. يتأكد إن إصدار الملف مش أحدث من التطبيق.
3. يتجاهل أي عمليات تالفة ويخبرك بعددها.
4. يعرض لك معاينة: كم عملية، كم فئة، وأي فترة زمنية.
5. يخيّرك بين طريقتين:
   - **دمج** — يضيف محتوى الملف لبياناتك الحالية. ما بينحذف شي. *(الأأمن)*
   - **استبدال** — يمسح كل شي ويحطّ محتوى الملف مكانه. *(لا يمكن التراجع)*

## حدود ومحاذير 📌

| | |
|---|---|
| **لا يوجد قفل للتطبيق** | أي شخص يفتح جهازك المفتوح يقدر يشوف مصاريفك. تقدر تستخدم زر **إخفاء المبالغ** 👁 في الأعلى كحل سريع. |
| **Face ID غير متاح** | تطبيقات PWA على iOS ما بتقدر تستخدم Face ID بشكل موثوق. هذا قيد من Apple وليس نقصًا في التطبيق. |
| **لا إشعارات** | إشعارات PWA على iOS غير موثوقة، فتُركت عمدًا. |
| **لا مزامنة سحابية** | كل جهاز له بياناته. للنقل بين الأجهزة استخدم النسخ الاحتياطي. |
| **المحلّل ليس مثاليًا** | يفهم أغلب الجمل الشائعة، وإذا ما فهم بيعرض لك النموذج اليدوي. تقدر تحسّنه بإضافة كلمات مفتاحية لفئاتك من: المزيد ← التصنيفات. |
| **عملات متعدّدة** | كل عملة تُحسب منفصلة، ما في تحويل تلقائي (لأنه يحتاج إنترنت وأسعار صرف). |

## للمهتمّين بالتفاصيل التقنية

<details>
<summary>البنية والتقنيات</summary>

**التقنيات:** React 19 · TypeScript · Vite · Dexie (IndexedDB) · vite-plugin-pwa

**بدون:** أي مكتبة رسوم بيانية (الرسوم مكتوبة يدويًا بـ SVG) · أي مكتبة أيقونات · أي API مدفوع · أي أداة تتبّع أو تحليلات.

```
src/
├── components/   نظام التصميم: أزرار، بطاقات، ألواح، رسوم بيانية، أيقونات
├── db/           قاعدة البيانات، الفئات الافتراضية، طبقة الوصول للبيانات
├── features/     الشاشات: اللوحة، السجل، التقارير، الميزانيات، الإعدادات…
├── hooks/        استعلامات حيّة، الثيم، الفترات الزمنية
├── services/     المنطق النقي: المال، التواريخ، المحلّل، التحليلات، الرؤى، النسخ
├── styles/       رموز التصميم والأنماط العامة
└── types/        تعريفات الأنواع
```

**قواعد مهمّة في الكود:**

- **المال:** كل المبالغ تُخزَّن كأعداد صحيحة بالوحدة الصغرى (أغورة). لا توجد أي عملية حسابية على أعداد عشرية، فلا يحدث خطأ `0.1 + 0.2 = 0.30000000000004` أبدًا.
- **الألوان:** لا يوجد أي لون مكتوب مباشرة داخل المكوّنات — كلها متغيّرات CSS في `src/styles/tokens.css`.
- **الاتجاه:** يُستخدم `inline-start`/`inline-end` بدل `left`/`right` في كل مكان، فالتطبيق RTL بنيويًا وليس بمجرّد محاذاة نص.
- **الأرقام داخل نص عربي:** تُغلَّف بـ `<span className="num">` وحدها فقط — إذا غُلِّف معها نص عربي ينقلب الترتيب.
- **قاعدة البيانات:** الترحيلات مُعدّة من البداية عبر `db.version(n)`. لا تحذف تعريف إصدار قديم أبدًا.

</details>

١٣٨ اختبارًا تغطّي المنطق الحسّاس:

- **المحلّل العربي** — جمل حقيقية بالعامية، أرقام عربية وهندية، أخطاء إملائية، تواريخ نسبية.

- **الميزانيات** — نسب الاستهلاك وحالات التحذير والتجاوز.

<details>
<summary>إضافة ذكاء اصطناعي لاحقًا (اختياري)</summary>

المحلّل الحالي يعمل محليًا بالكامل وبدون أي تكلفة. إذا حبيت لاحقًا تضيف نموذج ذكاء اصطناعي لتحسين الفهم، البنية جاهزة:

كل منطق التحليل معزول في `src/services/parser/`، وواجهته دالة واحدة:

```ts
parseArabicTransaction(text, ctx): ParsedTransaction
```

تقدر تضيف مزوّدًا جديدًا يستدعي API خارجيًا ويرجّع نفس الشكل، ويبقى المحلّل المحلي كبديل احتياطي عند انقطاع الإنترنت. بقية التطبيق ما تحتاج أي تعديل.

⚠️ **تنبيه خصوصية:** أي مزوّد خارجي معناه إرسال نص مصاريفك إلى خادم غير خادمك. ولا تضع مفتاح API داخل كود الواجهة أبدًا — سيكون مكشوفًا لأي شخص.

</details>
